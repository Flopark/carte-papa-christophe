# Carte pour Christophe

Une page autonome créée pour le 28 octobre 2026, signée FloFlo.

## Photos

Déposer les photos dans photos/, puis compléter la liste de photos.js. Le champ hero: true choisit la photo principale. Le champ position règle le cadrage. Les photos sont affichées en galerie et s’agrandissent au clic. Sans photo, la page affiche des cadres provisoires explicitement signalés.

## Publication GitHub Pages

Créer un dépôt public séparé, y envoyer les fichiers de ce dossier, puis choisir Settings → Pages → Deploy from a branch → main → /(root) → Save.

Adresse prévue, à confirmer après publication : https://flopark.github.io/carte-papa-christophe/

Documentation : https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-github-pages-site

## Contenu

Texte et structure : index.html. Couleurs et mise en page : style.css. Interactions : script.js. Pas de dépendance externe, pas d’outil de suivi, pas de formulaire. Le site fonctionne aussi en ouvrant index.html directement. Le contenu porte une instruction noindex : cela décourage l’indexation mais ne constitue pas une protection d’accès.
